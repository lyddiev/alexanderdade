WritingSamples

Five samples from the last few years. Each page says what the document was for and what to notice in how it’s written, then shows the document itself. Four sample procedures, troubleshooting SOPs, and knowledge base articles.−19 words

  • 1 Sample 1. Resolving a monetization issue Help center article for support agents One article from a 100-article knowledge base for a new support team. Every article shares the same table and headers, so agents can move between them without relearning the page.
  • 2 Sample 2. Cooling wind failure Troubleshooting SOP for a glass manufacturing plant A troubleshooting procedure from the library I built for a new manufacturing facility. Symptoms and causes come first, then the checks in the order an operator would make them.
  • 3 Sample 3. Localizing content in Heretto Procedure for technical users in a component content management system How to prepare content for translation, create a localization job, and exchange packages with a translation team. Part of an enterprise content migration to XML.
  • 4 Sample 4. Routing documents through review Procedure for a regulated review and approval workflow An Agile QA system for creating and updating controlled content, so documentation stays compliant without slowing down every change.
