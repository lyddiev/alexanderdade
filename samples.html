Writing samples

Procedures, troubleshooting SOPs, and knowledge base articles by Alexander Dade.

The writer

A technical writer first: a degree in technical writing, then lead technical writer at Concentrix. As a technical program manager since, still writes the procedures, runbooks, and knowledge bases his programs depend on, and writes for clients through Doc & Writer Consulting.

Each sample says what the document was for and what to notice in how it’s written, then shows the document itself.

Samples

  • A Appendix A. Resolving a monetization issue Help center article for support agents One article from a 100-article knowledge base for a new support team. Every article shares the same table and headers, so agents can move between them without relearning the page.
  • B Appendix B. Cooling wind failure Troubleshooting SOP for a glass manufacturing plant A troubleshooting procedure from the library I built for a new manufacturing facility. Symptoms and causes come first, then the checks in the order an operator would make them.
  • C Appendix C. Localizing content in Heretto Procedure for technical users in a component content management system How to prepare content for translation, create a localization job, and exchange packages with a translation team. Part of an enterprise content migration to XML.
  • D Appendix D. Routing documents through review Procedure for a regulated review and approval workflow An Agile QA system for creating and updating controlled content, so documentation stays compliant without slowing down every change.
  • E Appendix E. Sharing a route between screens Procedure for an in-vehicle interface A short procedure that makes an advanced in-car feature easy to use: sending a route from the passenger screen to the driver.
